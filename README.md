# Dimensionamento Chiese Audio — Flutter V1

Prototipo Android/Windows-ready per dimensionamento preliminare di sistemi a 100 V in chiese.

Modelli inclusi:
- DAP CS-330: prese 10/20 W, sensibilità 91 dB.
- Colonna 50 W: prese 12,5/25/50 W, sensibilità 91 dB, dispersione dichiarata 160° x 160°.

La V1 calcola numero indicativo, presa, carico totale, amplificatore con margine, interasse e altezza di installazione e mostra uno schema.

Per compilare:
`flutter pub get`
`flutter build apk --release`
